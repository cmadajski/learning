# Terraform Basics

## Fundamental Commands

- `terraform init`
- `terraform plan`
- `terraform apply`
- `terraform fmt`
- `terraform destroy`

## Terraform Concepts

Terraform is an Infrastructure as Code tool that allows for easier infrastrucutre management.

All the data for resources being managed by Terraform are contained in a **state** file. The state file can be local or remote depending on how you decide to configure it.

Terraform **resources** are used to create, modify, and destroy infrastructure. Terraform **data sources** are used exclusively for reading existing data.

Terraform has **providers** that act as plug-ins for 3rd party services. You can selectively install these providers to add functionality to Terraform for common services like AWS, Azure, and more.
